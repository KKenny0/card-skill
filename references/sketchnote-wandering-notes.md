# Sketchnote 漫游札记：意象、节奏与断行

## 适用与完成条件

所有 sketchnote 请求只使用本风格；允许按内容改变构图，不提供旧风格入口。使用 `mode: "sketchnote"`、`variant: "wandering-notes"`。这是一套共享排版基础和编辑规则，不是固定站点模板。1080px宽，长度随内容；不强制3:4。默认在360px图宽下检查实际PNG。

已验证范围：卢梭的当下安顿、不确定性的提问转向、A2A的协作边界。它们只覆盖所提供的正文片段。不能据此声称全部题材可迁移或读者已形成品牌识别。

## 先写清内容关系

在已有 `visual_plan.core_message / visual_metaphor / layout_strategy` 中说明：

1. 来源里的起始处境和认识转向分别是什么，哪些边界在转向后仍成立。
2. 同一意象保持什么、改变什么；变化如何对应内容，而非只换颜色或加装饰。
3. 哪里快读、哪里停顿、哪里回望；为何需要再次出现意象。

无需新增形式化叙事元数据。只有内容支持的关系才能进入画面。开放问题标明为阅读提问；不编造作者经历、失败、解决结果、数字或协议细节。

## 意象变化

- 先选可反复识别的物件或场景，再选择有意义的状态变化。保持轮廓、位置、角色等辨识线索。
- 一次意象已有足够职责时不重复；两次有变化时优先紧凑场景带，或利用正文旁已预留的空白。不是所有图都必须有“两幅前后图”。
- 变化应直接服务认识：卢梭的小舟与外界标签不变，压力线变为注意力围合；不确定性的小路和问号不变，注视圈移回当前位置；A2A的门始终关闭，门外新增交接纸张。
- 保留未解决部分。不能把问号变成答案、把关闭的门打开、把外界压力抹掉，导致读者误以为问题已经消失。
- 意象不是证据或实现图。容易误读时提供简短可见说明；复杂关系不能靠隐喻代替。
- 删去意象后若正文毫无损失、意象也不影响理解，检查它是否仅为装饰。若只有加大量标签才能理解，考虑解释图模式。

## 阅读节奏

先选一条认识线索，再组织自然长度的段落。不是把摘要拆成四个等大的格子。

- 卢梭：外界处境、停问、当下安顿、保留边界；回望式节奏。
- 不确定性：完整疑问、短暂停顿、突出新的提问、承认未知；转向处集中强调。
- A2A：委托场景、内部不可见的疑问、对外交接约定、命名与开放问题；从具体场景推进。

同级内容可稳定对齐；用语义分组而非统一大空白。不得为了压缩长度减小正文、删除条件或把所有段落塞成一块。优先移除重复图注、缩短没有独立职责的画面空白。删除整幅图前检查其变化是否仍能被读到。

## 正式样式与构图接口

renderer 注入 `assets/sketchnote-wandering-notes.css`。字体沿用已验证模板 `--serif`，不由tone改变。共享样式提供：

| 类 | 职责 |
|---|---|
| `.head`, `.k` | 标题区与来源主题提示；不自动填写作者 |
| `.scene` | 紧凑意象带，SVG应有准确viewBox |
| `.pause`, `.demand` | 阅读停问、初始要求；按需要选，不必须出现 |
| `.quiet`, `.pivot` | 缓读段与转向标题 |
| `.question`, `.line` | 核心问句；完整分句可分行 |
| `.ending`, `.open`, `.muted` | 边界、开放问题和次要说明 |
| `.whole` | 仅对已实测放得下的短语防断行 |

基础正文44px/1.6、次要说明36px/1.5、标题76px、段标题54px、页边56px。干净纸底，取消grain，颜色继承token。`custom_css`仅补充内容特有布局；不可用压字、裁切、超出父容器或极小字解决拥挤。

题材特定插图仍由Agent写入 `content_html`；renderer不会固定生成小舟、道路或门。模板无默认署名。完整可运行合同见 `evals/fixtures/sketchnote-wandering-notes/` 的三个Visual Job。

## 中文断行

1. 正文默认自然换行，`line-break: strict`、`word-break: normal`；`text-wrap: pretty`只是辅助，不是正确断行的保证。
2. 短问句宽度足够时不插入br。例如“先保证不会后悔，才能开始吗？”保留一行。
3. 核心长问句按完整分句断行，而非每个逗号后都换行。“20年后，没有选择哪件事， / 会让自己更遗憾？”保留两个语义单元。
4. 不让英文术语与谓语成为残短尾行；A2A首段按委托对象/接收者分两行，而非只剩“Agent评估”。
5. `.whole`只用于短语；先测剩余行宽，放不下就重新分句或调整合法布局，不为整段设nowrap。
6. 全图逐行检查句读：无孤立标点、无被拆开的关键短语、无为了对齐而产生的碎句。标题允许有意分行，正文不照搬标题节奏。

## 验证与边界

完成标准包括输出检查和宿主查看真实PNG。机器能检查越界、最小字号与合同，不能判断隐喻是否恰当、断行是否自然。

检查全图与360px图宽：核心问题完整可读，意象变化可辨认，图文不重叠，重复画面有独立职责，来源限制仍可见。既要检查段落框，也要看实际行内断点。题材专用绝对定位插图必须在父框预留空间，与每行文字的实际矩形无交集。

`node scripts/validate-sketchnote-notes.mjs` 验证三个样例的生产输出、关键断行、短语边界及省略variant默认样式。它不证明任意长句都能自动排好；内容增加后需要重新规划与实际看图。来源很长、有多条认识线索时先选明示范围或拆分阅读职责，不把每篇都强压到现有样例高度。
