# Infograph 比较札记

## 正式入口与能力

`mode: "infograph"` 默认且只采用比较札记，可显式写 `variant: "comparison-notes"`。继续使用 Studio 的非空 `content_html` 和 `custom_css`，经过 Visual Job v3、候选渲染、check-output、实际 PNG 审核和本地交付。共享样式不是固定表格，不限制数据、图表、结构展示或完整构图能力；不要把所有信息图强制改成选型表。不支持的 variant 明确报错。

renderer 自动注入 `assets/infograph-comparison-notes.css`：干净纸面、左对齐标题、细线分组、克制重音；1080px 宽、自然高度。默认正文40px/1.65，标题62px；密集内容正文不得低于36px。拆图详页推荐42px。tone/design 只改变颜色。`custom_css`补充实际布局，不用缩字、裁切或溢出来消化内容。

## 先决定比较什么

在现有 `visual_plan.core_message / layout_strategy / visual_hierarchy` 写清：比较对象、共同维度、证据范围、阅读重点、单图或拆图的理由。无需新增空洞的元数据字段。

- 对象按相同问题比较；条件不同、资料缺失或无法直接比较时显式说明。没有数据不填零、不猜测。
- 同级对象同等视觉权重；只有来源支持主次时才突出某项。不把协议或工具排成无依据的先进程度榜。
- 选型可先呈现接口或职责，再分“考虑”和“边界”宽行；不把长条件挤进第三个窄列。
- 表格适合同维度横向扫描。若连续阅读条件更重要，可改为分组札记；保留稳定的维度标签与顺序。
- 标题提出真实问题或有条件的判断，不把建议写成无条件结论。个人声音来自证据取舍与边界意识，不编造第一人称体验。

## 指标口径与阅读重音

每个数值邻近标明衡量对象、单位和必要条件；涉及比较时保留基准、样本、时间或设备范围。阈值、实测值、发布方报告、编辑推断必须区分。

- 不同对象的百分比不能相加或共用暗示可比性的柱形刻度。相同单位也不自动意味着同一口径。
- 来源给出综合结果时，可先突出该结果，再展开局部观察。不得把所选局部指标宣称为全部贡献。
- 没有综合数值时不造总分。共同判定规则可以成为主重音，多个指标仍同级呈现。
- 案例：Cursor 的综合成本降幅与局部指标分层；网页性能的三项良好阈值各自带单位，共同保留设备分组和第75百分位条件。
- 图表仍可用，但必须有可核对的数据与诚实的轴、单位、基准。不能用装饰图形伪造数量关系。

## 条件与中文断行

条件、否定、例外必须出现在可见正文，不仅存在于 evidence 或脚注里。条件与对应判断放在同组；来源说明可较小，影响采用的边界仍是正文。

1. 优先加宽条件行、减少重复旁注或拆分页面，不压缩字号。
2. 自然换行配合语义检查；`text-wrap: pretty`只辅助，不保证正确。
3. `.reading-unit` / `.unit`只保护已测量放得下的短语，例如“版本与支持”“缩短 LCP”。不要给整句加nowrap。
4. 关键谓语、术语与单位不落成孤立尾行；无孤立标点。长句可按完整分句停顿，不按每个逗号机械断行。
5. 查看原始PNG和360px缩略图，逐行核对；字数统计不能代替看图。

## 单图与总览＋分组详页

不设“超过四个对象就拆图”的机械阈值。按任务选择：

| 使用任务 | 优先方案 | 代价 |
|---|---|---|
| 经常跨组对照、条件能读清 | 单图，稳定维度与分组 | 长图滚动距离可能较大 |
| 先定位问题，再查适用条件；长句已使查找费力 | 总览＋分组详页 | 跨组翻页、导航重复、总阅读量增加 |
| 必须让全部对象同时比较，但单图不可读 | 重新选择比较维度或与用户协商范围 | 不可悄悄删条件或缩字 |

拆图规则：
- 总览保留全部对象、分组依据和各对象职责，明确“定位页”；不把缺少条件的摘要变成采用建议。
- 详页按真正共同的问题分组，保持同组对象在一起。不得为等页数平均切割。
- 每项完整条件与边界至少在对应详页出现一次。详页可单独理解，重复必要共同限制，但不重复整篇内容。
- 所有PNG写可见页码、组名、总览与详页去向；网页按钮不能代替PNG导航。
- 页长随内容；位移组只有一个对象也自然收尾，不补空白或编造对象。交互组较长时先检查组内可比性，再决定是否继续拆分。
- 每张有独立职责，写成独立output；每个output的artifact_index从1开始。共享证据可以引用，多页不可只有总览承担完整证据。

## 回归与审核

可运行合同位于 `evals/fixtures/infograph-comparison-notes/`：A2A四选项、Cursor综合与局部、三指标口径、六动作长图及四张拆图。`node scripts/validate-infograph-notes.mjs` 验证真实渲染、合同、内容保留、同级字号、短语断行、导航和颜色不改几何。

机器不判断比较维度是否正确、阅读是否自然、跨页成本是否值得。宿主须看每张实际PNG及360px预览，并核对来源。已验证只覆盖这些题材，未证明所有数据结构或真实读者阅读速度。单图与拆图均保留，不把一种布局固定为全局模板。
