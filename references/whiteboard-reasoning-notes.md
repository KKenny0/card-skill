# 推演札记：构图与拆图

## 目标与默认

呈现问题如何走到判断，同时保留依据、反例、否定、例外与未知。自然语言 whiteboard 默认 variant: reasoning-notes；配色按任务选择，沿用个人实验时可用 sharp。字体与关系布局不依赖颜色。不要把每篇文章硬套三段，不把摘要换成装饰框。

先按来源找关系，再明确选择块布局：边界用 boundary；期待与现实、原判断与反例用 opposition；认知转折用 turn；并列分支用 columns；跨层共享例外用 exception。选择是编辑判断，渲染器不从关键词或节点数量推断。

## 单图还是总览＋局部

默认优先单图，适合连续读完、关系能在一张内追踪的短推演。长条件、反例或三段分支本身不构成必须拆图。用户指定单张时优先遵守；若无法同时保留内容和可读字号，说明冲突，不静默拆分。

当共享例外覆盖多个阶段、存在跨层回跳、或用户主要按具体问题查阅，考虑总览＋局部。判断标准是每个局部能否独立回答一个问题，而非节点数或固定高度。超过三段、共享例外和回跳是启动检查的信号，不是已验证的硬上限。

拆图增加标题、入口、出口和重复条件；总阅读量可能更大。不得宣称拆图必然更快、更短。保留单图用于完整阅读，拆图用于选路查阅；用户没要求对照时，只交付适合任务的一套。

## 拆图计划

1. 先列完整语义清单：正常顺序、每个判断条件、同时满足/任一不满足、优先例外、终止状态、回跳目标和恢复步骤。
2. 总览只负责选路，写清异常优先级，并指向局部；不把完整细节再复制一遍。
3. 按可独立回答的问题拆局部，不按图片高度截段。每张局部写进入条件、结果/停止条件、恢复出口。仅复制正确使用该页所必需的上下文。
4. 为每页分配独立主要证据职责。source_units 应按真实语义切分，不伪造多份相同证据凑图数；总览负责路径关系，局部负责各自判断细节。可共享辅助证据，但每页仍需独有当前主要证据。
5. 整组放在同一 Visual Job 的多个 outputs 中，每个 output 一张 whiteboard PNG；不能将需要互相跳转的页分别做成独立 Job 后冒充已校验系列。

## 结构化导航

为每个拆图合同提供 note_page，variant 必须为 reasoning-notes：

```json
{
  "series": "publishing", "id": "02", "role": "detail",
  "entry": "任何阶段发现缺来源或数据冲突，先暂停并核对。",
  "exit": "修正后重审、排版，再重新确认；不能原地续发。",
  "links": [{"target": "03", "label": "重审排版后，进入发布确认"}]
}
```

role 为 overview 或 detail。series 标识一组拆图；id 是在同组内唯一的可见编号。entry、exit 和 links 都会渲染，须是读者可用的文字，不是实现说明。正文不要再复制相同入口出口，也不要把不存在的编号写进正文。单图不填 note_page。

同组在一个 Job 内必须有且只有一张总览、至少一张局部，所有 target 必须存在，不能自指或重复；每张局部必须从总览可达。允许跨页回跳环，例如02完成后去03、03遇到事实问题回02，图遍历不会无限循环。编号可重排，关系不依赖 outputs 的数组位置。跨组不互跳。

程序只验证声明的导航图，不会理解正文里偷偷写的编号或逻辑。审核时人工逐一核对正文、links、实际PNG，确认条件和返回路径一致。终止局部可无 links，但必须写清 exit。

## 小屏与边界

正文44px、旁注42px不因内容过长而缩小。优先压缩授权范围内的重复表达，按语义断行，保留条件；必要时改分组。单块1–3栏，opposition三节点，boundary两栏，depth最多2，每张最多16块。这些是实现支持边界，不代表可读性保证。超过边界重新规划，不截断、不隐藏。

以实际360px图宽检查；不能把不同高度的图缩成同高缩略图来比较。长图可自然增高，不绑定Poster的3:4。过长单词、长标签、无效父条件或复杂交叉回路需要重新编辑/拆图，而非靠缩字修复。

## 交付审核

- 来源和假设明确区分；标题不把被反驳观点改成结论。
- 每条有效路径都有结果，未满足路径不会误入下一层；优先例外覆盖所有应覆盖阶段。
- 反例写明推翻什么、没有证明什么；不推断原文未支持的因果。
- 局部图独立查看时仍能辨认入口、停止和去向；回跳后需要重做的步骤可见。
- 灰度可识别关系，360px可读，无裁切、重叠、碎字孤行；逐张查看真实PNG。
- 通过自动检查不等于读者速度或品牌识别已验证。当前样例覆盖边界、转向、长条件、反例、三段分支、共享例外与一次跨层恢复；未证明任意图结构适用。
